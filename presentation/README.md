# Презентация на основе Beamer (`moloch` шаблон)

Этот проект содержит шаблон презентации для конференций и выступлений, оформленный с использованием темы `moloch` на базе LaTeX Beamer. Основной язык документа — **русский**, с поддержкой английского.

## Структура проекта

- `name_main.tex` — основной файл презентации.
- `slides/` — папка со слайдами, которые подключаются через `\input`.
- `my_ref.bib` — файл библиографии.
- Папки `pdf/`, `png/`, `svg/`, `pics/`, `Figures/` — папки с изображениями.

## Требования

- Установленный LaTeX (например, TeX Live или MiKTeX).
- Установленные пакеты: `beamer`, `minted`, `biblatex`, `pgfplots`, `babel`, `fontspec`, `svg`, `fancyvrb` и др.
- Установленный компилятор `latexmk` (рекомендуется).

## Инструкция по сборке

Для корректной сборки презентации необходимо использовать `pdflatex` с разрешением выполнения внешних команд (опция `-shell-escape` для корректной обработки `minted` и `svg`).

В терминале выполните команду:

```bash
pdflatex -shell-escape -synctex=1 -interaction=nonstopmode name_main.tex
```

**Рекомендуется использовать** автоматическую сборку с помощью `latexmk`:

```bash
latexmk -pdf -shell-escape -synctex=1 name_main.tex
```

## 📄 Особенности

- Используется шрифт **Fira Sans** для основного текста.
- Математические формулы оформляются в стиле `serif`.
- Подключение векторных изображений в формате `.svg` через пакет `svg`.
- Организация проекта предполагает раздельное хранение содержимого слайдов.
- Библиография подключается через `biblatex` и `biber`.

## 📝 Примечания

- Если используется `minted`, необходимо наличие установленного `Python` и `Pygments`.
- Для работы с `.svg` файлами нужен установленный `Inkscape` (если требуется конвертация в PDF через пакет `svg`).
